# Security Policy

Thanks for helping keep GoSFU safe.

## Reporting a Vulnerability

If you find a security issue, please do not open a public issue.

Report it privately by emailing `jsgokul123@gmail.com` or by using GitHub's private vulnerability reporting if it is enabled for the repository.

Please include:

- A short description of the issue.
- Steps to reproduce it.
- The affected area, such as WebRTC transport, room/session handling, provider credentials, or frontend behavior.
- Any logs, screenshots, or proof-of-concept code that helps explain the impact.

## What to Avoid

Please do not:

- Publicly disclose the issue before it has been reviewed.
- Access data that does not belong to you.
- Run destructive tests against deployed services.
- Commit secrets, API keys, `.env` files, credentials, or private model artifacts.

## Response

I will review valid reports as soon as possible and follow up with questions, a fix plan, or a disclosure timeline when appropriate.
